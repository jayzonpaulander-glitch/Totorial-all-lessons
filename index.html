02 HTML · SIDANS INNEHÅLL

HTML ger sidan
sin struktur.

HTML står för HyperText Markup Language. Taggar berättar för webbläsaren vad innehållet är — till exempel en rubrik, ett stycke eller en bild.

01

Rubriker

Använd <h1> till <h6>. H1 är viktigast; h6 är minst. Tänk på rubriker som en tydlig innehållsordning.

<!-- Sidans huvudrubrik -->
<h1>Min första sida</h1>
<h2>En underrubrik</h2>
02

Text & radbrytning

En paragraf använder <p>. Taggen <br> bryter raden, men använd ett nytt stycke när texten börjar ett nytt resonemang.

<p>Det här är ett stycke text.</p>
<p>En ny tanke får ett eget stycke.</p>
03

Länkar & bilder

Länkar använder href. Bildens src anger sökvägen och alt beskriver bilden för den som inte kan se den.

<a href="https://www.w3schools.com">
  Besök W3Schools
</a>
<img src="images/bild.jpg"
  alt="En beskrivning av bilden">
04

Betoning & kommentarer

<b> gör text fet och <i> kursiv. En kommentar finns i koden, men visas inte på själva sidan.

<b>Viktig text</b>
<i>Betonad text</i>
<!-- Den här kommentaren
     syns inte på hemsidan. -->
i

Var ska bilden ligga? Om du skriver src="images/bild.jpg" ska bildfilen ligga i en mapp som heter images, bredvid din index.html.

03 CSS · SIDANS UTSEENDE

CSS är färg,
form och känsla.

CSS står för Cascading Style Sheets och bestämmer hur HTML-innehållet ser ut. Du kan skriva CSS på tre sätt:

01

Inline

Direkt i ett HTML-elements style-attribut. Det är metoden vi börjar med.

style="color: white"
02

Internal

I ett <style>-block i sidans <head>.

<style> … </style>
03

External

I en separat .css-fil som länkas in i HTML-dokumentet.

style.css
PROVA SJÄLV

En rad kod.
En helt ny känsla.

Ändra färgen, storleken eller bakgrunden. Spara filen och uppdatera webbläsaren för att se skillnaden.

index.html
<body style="background-color: #10110f; color: white;">
  <h1 style="font-family: Georgia; text-align: center;">
    Min fina hemsida
  </h1>
  <p style="font-size: 18px;">Hej världen!</p>
</body>

05 FRÅN DIN DATOR TILL GITHUB

Din sida förtjänar
att komma ut.

GitHub sparar och delar din kod. När du har skapat ett repo kan du skicka upp nya ändringar från terminalen.

1

Skapa ett repo

Skapa ett nytt repository på GitHub, eller använd ditt befintliga. Kopiera projektet till rätt mapp.

2

Öppna terminalen

Öppna projektmappen i Utforskaren, klicka i adressfältet, skriv cmd och tryck Enter.

3

Spara och skicka upp

Kör kommandona nedan. Commit-meddelandet beskriver vad du ändrade.

TERMINAL
$ git add .
$ git commit -m "Lägg till bakgrundsfärg"
$ git push
↗

Efter uppladdningen kan du publicera projektet med GitHub Pages. Följ kursens GitHub-guide för instruktioner.
